# ELI5 — CLI-калькулятор

Представь калькулятор, где ты пишешь всё выражение сразу.

- Пишешь `2 + 3 * 4` — получаешь `14` (он знает, что `*` важнее `+`).
- Скобки работают: `(2 + 3) * 4 = 20`.
- Если написать `1 / 0`, он не упадёт — скажет "деление на ноль".
- Ерунда вроде `2 +` — "неверный синтаксис".

Внутри мы не используем опасный `eval()` (он может выполнить любой код). Вместо этого превращаем твою строку в маленькое дерево (`ast`) и разрешаем только числа и `+ - * / // % **` — ничего лишнего не проскочит.

Запусти `python -m cli_calculator` без аргументов — получишь мини-чат: вводишь `>>`, он отвечает, пока не напишешь `exit`.

Всё — безопасный, типизированный, протестированный калькулятор, который можно скопировать одной папкой.
