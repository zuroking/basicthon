# ELI5 — Организатор файлов (для самых маленьких)

Представь захламлённый ящик стола.

- Высыпаем всё на стол: фотки, документы, музыка, фильмы.
- `get_category` — наклейщик: смотрит на расширение (`.jpg` → `images`, `.pdf` → `documents`, `.zip` → `archives`, нет расширения → `others`).
- `organize(source, dest)` — руки, которые раскладывают: берут каждый файл из `source`, спрашивают наклейщика и кладут в `dest/images/` или `dest/documents/` и т.д.

Правила для ребёнка:

- Если в ящике уже есть `photo.jpg`, кладём как `photo_1.jpg`, потом `_2`.
- Папки на столе не трогаем — только файлы.
- `dry_run=True` — показываем пальцем "я бы положил сюда", но не двигаем.

Всё — наклеил, перенёс, при коллизии переименовал, папки пропустил. CLI просто печатает `photo.jpg -> images/`.
