# ELI5 — Поиск дубликатов (для самых маленьких)

Представь учителя, который проверяет, списали ли дети домашку.

- `hash_file` — машинка для отпечатков: читает байты файла кусочками, кормит `sha256`, выдаёт 64-символьный отпечаток. Одинаковое содержимое → одинаковый отпечаток, разное → разный.
- `find_duplicates(directory)` — детектив: проходит по папке (и всем подпапкам если `recursive=True`), снимает отпечаток каждого файла, складывает одинаковые в кучки. Кучки где `>1` файла — дубликаты.

Правила для ребёнка:

- Если файла нет → ошибка. Если путь — папка → ошибка.
- `recursive=True` смотрит везде (`rglob`), `False` — только верхний уровень (`iterdir`).
- Каждая кучка отсортирована, чтобы тесты видели один порядок.
- Пустые файлы тоже имеют отпечаток — два пустых считаются дубликатами.
- CLI просто печатает `hash ...:` и список файлов, или "no duplicates found".
