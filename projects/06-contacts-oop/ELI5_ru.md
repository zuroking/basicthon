# ELI5 — Контакты ООП (для самых маленьких)

Представь бумажную записную книжку.

- `Contact` — одна карточка: сверху `name`, посередине `phone`, снизу `email`. Прежде чем положить карточку, проверяем: имя не пустое (1-100), телефон — 5-15 цифр и только `+ - ( ) .` и пробелы, email — есть `@` и `.`.
- `ContactBook` — коробка с карточками. Раскладывает по `name.lower()`, поэтому `Alice` и `alice` — один слот, дубликаты нельзя.

Что можно делать:

- `add` — положить карточку. Если имя уже есть → ошибка.
- `get` — достать по имени (`alice` найдёт `Alice`). Нету → `None`.
- `update` — поменять телефон или почту. Нету → ошибка.
- `delete` — выбросить карточку. Нету → ошибка.
- `search` — потрясти коробку, оставить где запрос внутри `name/email/phone` без учёта регистра. Пустой запрос → пусто.
- `list_contacts` — высыпать все карточки отсортировано по имени (`alice, Bob, Charlie`).

Всё — проверили одну карточку, управляем многими, CLI просто сохраняет в `contacts.json` и печатает.
