# ELI5 — To-do CLI с JSON

Представь тетрадь для задач.

- Каждая страница — `TodoItem`: у неё есть номер `id`, заголовок `title` вроде "Купить молоко" и галочка `completed` (пусто или отмечено).
- Есть коробка (JSON-файл), где лежат все страницы. `save_todos` кладёт страницы в коробку, `load_todos` достаёт. Если коробки нет или она пуста — получаешь ноль страниц.

Что можно делать:

- `add "Купить молоко"` — смотрим на самый большой номер в стопке, прибавляем 1 и создаём новую страницу. Пустой заголовок `"   "` нельзя.
- `done 1` — находим страницу 1 и ставим галочку. Если страницы 1 нет — говорим "not found".
- `delete 1` — вырываем страницу 1. Если её нет — "not found".
- `list` — показываем страницы; `list --all` — все, иначе только неотмеченные. `list --json` печатает коробку как JSON.

Зачем файл? Чтобы задачи не исчезали после закрытия программы. Файл — просто JSON-массив, который можно открыть в любом редакторе:

```json
[{"id": 1, "title": "Купить молоко", "completed": false}]
```

Запусти `python -m todo_cli add "Купить молоко" && python -m todo_cli list --all` — и увидишь свою тетрадь.
