# ELI5 — Заметки на SQLite (для самых маленьких)

Представь маленький шкаф с одним ящиком `notes`.

- В ящике — карточки: `id` (номер), `title`, `content`, `created_at` (когда создана). `id` растёт сам 1,2,3.
- `create_db("notes.db")` строит шкаф и ящик, если их нет. Повторный вызов ничего не ломает.
- `add_note("Покупки", "купить молоко")` кладёт новую карточку, возвращает её номер `1`. Заголовок пустым быть не может.
- `get_note(1)` достаёт карточку 1; если нет — `None`.
- `list_notes()` высыпает все карточки по порядку номеров.
- `update_note(1, title="Новое")` переписывает поля карточки 1; если карточки нет — кричит `ValueError`.
- `delete_note(1)` вырывает карточку 1; если нет — кричит.
- `search_notes("покуп")` ищет кусочек `покуп` внутри `title` и `content` без учёта регистра (`LIKE %покуп%`), возвращает совпавшие.

Правила для ребёнка:

- Заголовок после `strip` не пустой; содержание может быть пустым.
- В SQL всегда `?` — никогда не склеивай строки в запрос.
- Тесты используют временный шкаф (`tmp_path / "notes.db"`) — настоящий файл SQLite, не подделка.
